

## Analisa singkat

1. **Desain protocol sudah bagus**
   - Header fixed 8 byte.
   - Little-endian eksplisit.
   - Opcode, layer type, variant, flags sudah jelas.
   - Cocok untuk komunikasi JS ↔ WASM.

2. **Parsing payload masih rawan offset manual**
   - Banyak `read_u32(payload, offset)`, `read_f64(payload, offset)`, dst.
   - Untuk `Option<u32>` dan `Option<f64>`, ukuran encoding harus konsisten.
   - Solusi terbaik: gunakan cursor/reader berurutan, bukan offset manual.

3. **`payload_len` belum dimanfaatkan**
   - Header sudah membawa `payload_len`, tetapi registry belum memvalidasi/motong payload berdasarkan nilai itu.
   - Solusi: validasi dan slice payload sebelum parsing.

4. **`total_params()` menghitung ulang semua layer**
   - Setiap panggil, semua HashMap di-iterate.
   - Solusi: simpan cache `cached_params`, update saat init/destroy/load state.

5. **Banyak duplikasi match layer type**
   - `init_layer`, `forward_layer`, `get_layer_state`, `load_layer_state`, `destroy_layer` semuanya match tipe layer.
   - Solusi bertahap: gunakan macro helper.
   - Solusi lanjutan: satukan layer dalam enum/trait + satu HashMap.

6. **Hasher default `std::collections::HashMap` cukup lambat untuk key u32**
   - Untuk WASM, `FxHashMap` atau `AHashMap` biasanya lebih cepat.
   - Bisa diganti drop-in.

# 1. Optimasi `protocol.rs`

Tambahkan cursor payload dan validasi `payload_len`.

Format option yang dipakai:

```text
Option<u32>:
  1 byte tag: 0 = None, 1 = Some
  4 byte value u32 little-endian, tetap ditulis walau None

Option<f64>:
  1 byte tag: 0 = None, 1 = Some
  8 byte value f64 little-endian, tetap ditulis walau None
```

Ini membuat ukuran option selalu tetap:

```text
Option<u32> = 5 byte
Option<f64> = 9 byte
```

## Tambahkan ke `protocol.rs`

```rust
pub const VARIANT_NONE: u8 = 0xFF;

pub const FLAG_BIAS: u8 = 1 << 0;
pub const FLAG_TRAINING: u8 = 1 << 1;

impl PacketHeader {
    /// Potong payload sesuai payload_len.
    #[inline]
    pub fn validate_payload<'a>(&self, payload: &'a [u8]) -> Result<&'a [u8], String> {
        let expected = self.payload_len as usize;

        if payload.len() < expected {
            return Err("payload shorter than payload_len".to_string());
        }

        Ok(&payload[..expected])
    }

    /// Tulis header ke buffer fixed 8 byte tanpa alokasi Vec.
    #[inline]
    pub fn write_to(&self, buf: &mut [u8; 8]) {
        buf[0] = self.opcode;
        buf[1] = self.layer_type;
        buf[2] = self.variant;
        buf[3] = self.flags;
        buf[4..8].copy_from_slice(&self.payload_len.to_le_bytes());
    }
}
```

Ganti `to_bytes` menjadi:

```rust
pub fn to_bytes(&self) -> Vec<u8> {
    let mut buf = [0u8; 8];
    self.write_to(&mut buf);
    buf.to_vec()
}
```

Tambahkan cursor:

```rust
pub struct PayloadCursor<'a> {
    data: &'a [u8],
    pos: usize,
}

impl<'a> PayloadCursor<'a> {
    #[inline]
    pub fn new(data: &'a [u8]) -> Self {
        Self { data, pos: 0 }
    }

    #[inline]
    fn ensure(&self, n: usize) -> Result<(), String> {
        let end = self
            .pos
            .checked_add(n)
            .ok_or_else(|| "payload offset overflow".to_string())?;

        if end > self.data.len() {
            return Err(format!(
                "payload out of bounds: need {} bytes at offset {}",
                n, self.pos
            ));
        }

        Ok(())
    }

    #[inline]
    pub fn read_u8(&mut self) -> Result<u8, String> {
        self.ensure(1)?;
        let v = self.data[self.pos];
        self.pos += 1;
        Ok(v)
    }

    #[inline]
    pub fn read_u32(&mut self) -> Result<u32, String> {
        self.ensure(4)?;

        let b = [
            self.data[self.pos],
            self.data[self.pos + 1],
            self.data[self.pos + 2],
            self.data[self.pos + 3],
        ];

        self.pos += 4;

        Ok(u32::from_le_bytes(b))
    }

    #[inline]
    pub fn read_f32(&mut self) -> Result<f32, String> {
        self.ensure(4)?;

        let mut b = [0u8; 4];
        b.copy_from_slice(&self.data[self.pos..self.pos + 4]);

        self.pos += 4;

        Ok(f32::from_le_bytes(b))
    }

    #[inline]
    pub fn read_f64(&mut self) -> Result<f64, String> {
        self.ensure(8)?;

        let mut b = [0u8; 8];
        b.copy_from_slice(&self.data[self.pos..self.pos + 8]);

        self.pos += 8;

        Ok(f64::from_le_bytes(b))
    }

    #[inline]
    pub fn read_bool(&mut self) -> Result<bool, String> {
        self.read_u8().map(|v| v != 0)
    }

    #[inline]
    pub fn read_usize(&mut self) -> Result<usize, String> {
        self.read_u32().map(|v| v as usize)
    }

    /// Option<u32> fixed-size:
    /// 1 byte tag + 4 byte value
    #[inline]
    pub fn read_option_u32(&mut self) -> Result<Option<u32>, String> {
        let present = self.read_u8()? != 0;
        let value = self.read_u32()?;

        Ok(if present { Some(value) } else { None })
    }

    /// Option<f64> fixed-size:
    /// 1 byte tag + 8 byte value
    #[inline]
    pub fn read_option_f64(&mut self) -> Result<Option<f64>, String> {
        let present = self.read_u8()? != 0;
        let value = self.read_f64()?;

        Ok(if present { Some(value) } else { None })
    }

    #[inline]
    pub fn read_option_usize(&mut self) -> Result<Option<usize>, String> {
        Ok(self.read_option_u32()?.map(|v| v as usize))
    }

    #[inline]
    pub fn remaining(&self) -> usize {
        self.data.len().saturating_sub(self.pos)
    }
}
```

Fungsi helper lama seperti `read_u32(payload, offset)` tetap bisa dipertahankan untuk kompatibilitas, tetapi untuk init layer sebaiknya pindah ke `PayloadCursor`.

# 2. Optimasi `registry.rs`

## 2.1 Gunakan hasher yang lebih cepat

Opsional tetapi sangat berguna untuk WASM.

`Cargo.toml`:

```toml
[dependencies]
rustc-hash = "2"
```

Lalu di `registry.rs`:

```rust
use rustc_hash::FxHashMap as HashMap;
```

Jika tidak ingin dependency tambahan, tetap gunakan:

```rust
use std::collections::HashMap;
```

Namun `FxHashMap` biasanya lebih cepat untuk key integer seperti `u32`.

## 2.3 Macro helper untuk update cache

Tambahkan macro di atas `impl LayerRegistry`:

```rust
macro_rules! insert_layer {
    ($self:ident, $map:ident, $id:expr, $layer:expr) => {{
        let new_params = $layer.num_params();

        if let Some(old) = $self.$map.insert($id, $layer) {
            $self.cached_params = $self.cached_params.saturating_sub(old.num_params());
        }

        $self.cached_params = $self.cached_params.saturating_add(new_params);
    }};
}

macro_rules! remove_layer {
    ($self:ident, $map:ident, $id:expr) => {{
        if let Some(old) = $self.$map.remove(&$id) {
            $self.cached_params = $self.cached_params.saturating_sub(old.num_params());
            true
        } else {
            false
        }
    }};
}

macro_rules! load_layer_state {
    ($self:ident, $map:ident, $id:expr, $data:expr) => {{
        match $self.$map.get_mut(&$id) {
            Some(layer) => {
                let old_params = layer.num_params();
                let result = layer.load_state($data);

                if result.is_ok() {
                    let new_params = layer.num_params();

                    $self.cached_params = $self
                        .cached_params
                        .saturating_sub(old_params)
                        .saturating_add(new_params);
                }

                result
            }
            None => Err("Not found".into()),
        }
    }};
}
```

```rust
fn init_activation(&mut self, header: &PacketHeader, payload: &[u8]) -> Result<(), String> {
    let mut c = PayloadCursor::new(payload);

    let id = c.read_u32()?;

    let layer = match header.variant {
        ACT_GELU => WasmActivation::new_gelu(),
        ACT_RELU => WasmActivation::new_relu(),
        ACT_SIGMOID => WasmActivation::new_sigmoid(),
        ACT_TANH => WasmActivation::new_tanh(),
        ACT_HARDSWISH => WasmActivation::new_hard_swish(),
        ACT_MISH => WasmActivation::new_mish(),

        ACT_LEAKYRELU => {
            let slope = c.read_option_f64()?;
            WasmActivation::new_leaky_relu(slope)
        }

        ACT_PRELU => {
            let num_params = c.read_option_usize()?;
            let alpha = c.read_option_f64()?;

            WasmActivation::new_prelu(num_params, alpha)
        }

        ACT_SWIGLU => {
            let d_in = c.read_usize()?;
            let d_out = c.read_usize()?;
            let bias = c.read_option_u32()?.map(|v| v != 0);

            WasmActivation::new_swiglu(d_in, d_out, bias)
        }

        ACT_HARDSIGMOID => {
            let alpha = c.read_option_f64()?;
            let beta = c.read_option_f64()?;

            WasmActivation::new_hard_sigmoid(alpha, beta)
        }

        ACT_SOFTPLUS => {
            let beta = c.read_option_f64()?;
            WasmActivation::new_softplus(beta)
        }

        ACT_SOFTMAX => {
            let dim = c.read_usize()?;
            WasmActivation::new_softmax(dim)
        }

        ACT_LOGSOFTMAX => {
            let dim = c.read_usize()?;
            WasmActivation::new_log_softmax(dim)
        }

        ACT_GLU => {
            let dim = c.read_usize()?;
            WasmActivation::new_glu(dim)
        }

        _ => return Err(format!("Unknown activation variant: 0x{:02X}", header.variant)),
    };

    insert_layer!(self, activations, id, layer);

    Ok(())
}
```

```js
  arr.push(
    v & 255,
    (v >>> 8) & 255,
    (v >>> 16) & 255,
    (v >>> 24) & 255
  );
}

export function writeF64(arr, value) {
  const buf = new ArrayBuffer(8);
  const view = new DataView(buf);
  view.setFloat64(0, value, true);
  arr.push(...new Uint8Array(buf));
}

export function writeBool(arr, value) {
  arr.push(value ? 1 : 0);
}

export function writeOptionU32(arr, value) {
  const present = value !== null && value !== undefined;

  arr.push(present ? 1 : 0);
  writeU32(arr, present ? value : 0);
}

export function writeOptionF64(arr, value) {
  const present = value !== null && value !== undefined;

  arr.push(present ? 1 : 0);
  writeF64(arr, present ? value : 0);
}
```

# 4. Optimasi lanjutan: satu registry terpadu

Registry saat ini memakai banyak HashMap. Ini masih bagus, tetapi bisa disederhanakan.

## Opsi A: enum layer


Buat key gabungan agar ID boleh sama antar tipe layer:

```rust
type LayerKey = u64;

#[inline]
fn make_layer_key(layer_type: u8, layer_id: u32) -> LayerKey {
    ((layer_type as u64) << 32) | (layer_id as u64)
}
```

Registry menjadi:

```rust
#[wasm_bindgen]
pub struct LayerRegistry {
    layers: HashMap<LayerKey, Box<AnyLayer>>,
    cached_params: usize,
}
```

Contoh forward:

```rust
#[wasm_bindgen(js_name = forwardLayer)]
pub fn forward_layer(
    &self,
    layer_id: LayerId,
    layer_type: u8,
    input: &WasmTensor,
) -> Result<WasmTensor, String> {
    let key = make_layer_key(layer_type, layer_id);

    self.layers
        .get(&key)
        .ok_or_else(|| "Layer not found".to_string())?
        .forward(input)
}
```

Contoh insert:

```rust
fn insert_any(&mut self, layer_type: u8, id: u32, layer: AnyLayer) {
    let key = make_layer_key(layer_type, id);
    let boxed = Box::new(layer);
    let new_params = boxed.num_params();

    if let Some(old) = self.layers.insert(key, boxed) {
        self.cached_params = self.cached_params.saturating_sub(old.num_params());
    }

    self.cached_params = self.cached_params.saturating_add(new_params);
}
```

Keuntungan:

- Satu HashMap.
- Satu dispatch point.
- API lebih sederhana.
- `layer_type` tetap bisa dipakai sebagai key.
- Tidak ada duplikasi HashMap per tipe.

Kekurangan:

- Ada satu alokasi `Box<AnyLayer>` per layer.
- Ukuran enum mengikuti variant terbesar.
- Untuk beban komputasi neural network, overhead ini biasanya kecil dibanding biaya forward.

# 5. Optimasi performa lain yang berdampak besar

## 5.1 Gunakan `f32` bukan `f64`

Saat ini protocol memakai `f64`. Untuk neural network inference/training ringan, `f32` biasanya lebih hemat memori dan lebih cepat.

Tambahkan reader `f32` sudah saya sertakan di cursor:

```rust
pub fn read_f32(&mut self) -> Result<f32, String>
```

Jika layer internal memakai `f32`, ubah:

```text
weight: Vec<f32>
bias: Vec<f32>
tensor: Vec<f32>
```

Protocol sisi JS juga perlu menulis `float32` little-endian.

---

## 5.2 Aktifkan WASM SIMD

Untuk operasi seperti linear, conv, norm, dan activation, SIMD bisa mempercepat.

Build dengan target feature:

```bash
RUSTFLAGS="-C target-feature=+simd128" wasm-pack build --target web
```

Lalu gunakan operasi vectorized di kernel layer, misalnya:

- dot product
- conv2d
- relu/gelu/sigmoid
- normalization reduction

---

## 5.3 Kurangi copy tensor

Jika `WasmTensor` sering dikonversi dari JS `Float32Array` ke `Vec<f32>`, itu mahal.

Desain yang lebih cepat:

- Simpan tensor sebagai `Vec<f32>` di Wasm memory.
- Forward antar layer memakai `&WasmTensor` atau `&[f32]`.
- Hanya input/output akhir yang pindah dari/ke JS.
- Hindari bolak-balik JS ↔ WASM untuk setiap layer.

---

## 5.4 Jalankan graph/sequence di Rust

Saat ini setiap layer bisa dipanggil satu per satu dari JS:

```js
registry.forwardLayer(id1, type1, tensor);
registry.forwardLayer(id2, type2, tensor);
registry.forwardLayer(id3, type3, tensor);
```

Ini menghasilkan banyak call JS ↔ WASM.

Lebih cepat jika punya satu call:

```rust
#[wasm_bindgen(js_name = forwardGraph)]
pub fn forward_graph(
    &self,
    layer_ids: &[u32],
    layer_types: &[u8],
    input: &WasmTensor,
) -> Result<WasmTensor, String>
```

Di dalamnya:

```rust
let mut tensor = input.clone();

for (&id, &layer_type) in layer_ids.iter().zip(layer_types.iter()) {
    tensor = self.forward_layer(id, layer_type, &tensor)?;
}

Ok(tensor)
```

Ini mengurangi overhead lintas batas JS-WASM.

---

## 5.5 Gunakan error yang lebih murah

`Result<T, String>` membuat alokasi string saat error. Untuk hot path, gunakan `JsError` atau error enum.

Contoh:

```rust
use wasm_bindgen::JsError;

#[wasm_bindgen(js_name = forwardLayer)]
pub fn forward_layer(
    &self,
    layer_id: LayerId,
    layer_type: u8,
    input: &WasmTensor,
) -> Result<WasmTensor, JsError> {
    match layer_type {
        LAYER_LINEAR => self
            .linears
            .get(&layer_id)
            .ok_or_else(|| JsError::new("Linear not found"))?
            .forward(input)
            .map_err(|e| JsError::new(&e)),

        // layer lain...
        _ => Err(JsError::new("Unknown layer type")),
    }
}
```

Untuk error internal layer, idealnya layer juga mengembalikan `Result<T, LayerError>` bukan `String`.
